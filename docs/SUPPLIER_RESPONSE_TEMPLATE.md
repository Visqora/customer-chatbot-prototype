## 6. Ownership confirmation

Confirm each statement with **Yes** or explain the exception:

- [ ] The client will own production accounts and recovery methods.
- [ ] The client will control provider billing.
- [ ] The client will own uploaded content, bot configuration, and business data.
- [ ] The client will have administrator access before final payment.
- [ ] No production dependency will use the supplier's personal account or payment method.
- [ ] Supplier access can be removed without disabling the chatbot.
- [ ] Available configuration and content exports will be delivered at handover.

## 7. Security and data handling confirmation

Confirm each statement with **Yes** or explain the exception:

- [ ] Only delegated, least-privilege access will be requested where available.
- [ ] Multi-factor authentication will be used where available.
- [ ] Credentials will not be sent through ordinary messages or stored in project files.
- [ ] No real customer data will be used in demos or acceptance tests.
- [ ] Client content and transcripts will not be reused without written permission.
- [ ] Credentials and local client-data copies will be deleted when no longer required.
- [ ] A suspected security or privacy incident will be reported promptly.

Describe the secure access method you propose and how deletion will be confirmed.
